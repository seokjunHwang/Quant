## 6. 경험 및 경력기술서

### [오퍼레잇 / 2025.11 ~ 현재]
- AI 차트예측 모델 개발 및 서비스 배포, 매매피드백 로직 개발 : 전략 설계, 백테스트, 예외처리, 실서버 배포 전 사이클 수행
- 트레이딩 전략 알고리즘 설계 및 PineScript, Python 차트지표 개발, 글로벌 경제시황 분석 기반 매매 로직 체인 연구
- Anthropic·Gemini API/CLI 활용 멀티 에이전트 오케스트레이션 설계 : 기획·생성·검수 역할 분리, 검색API, DB조회, 문서로딩 모듈 구현, 자동화 파이프라인 개발

### [해온에이아이랩 / 2025.09 ~ 2025.10]
- 요한슨 공적분 검정으로 종목 간 장기 균형 관계 검증, VAR·VECM 모델로 시계열 상호작용 반영한 차트 예측 알고리즘 개발
- 통계적으로 유의미한 종목군 페어링 → 트레이딩 후보군 도출, 종목추천 알고리즘 전략 수립
- 금융 시계열 데이터 전처리·머신러닝 학습·파인튜닝, 데이터 수집, 모델링, 배포·운영까지 end-to-end 단독 수행

### [서울아산병원 / 2024.03 ~ 2025.08]
- 환자 1,002명 CT 빅데이터 3D Segmentation 딥러닝 모델 개발, 팀(5명) 리드 및 기술적 의사결정 주도
- U-Net++·DeepLabV3+·DFN 파인튜닝 후 하드보팅 앙상블 — 인간 전문가 일치도(R²=0.76) 대비 재현성(R²=0.92) 달성, JACC 저널 1저자 초록 등재(TCT-1176)
- 모델 예측, 타겟 서칭, 수치 계산 전 과정 Python 자동화 구현, 자체 알고리즘 창안(ConvexHull·Voronoi·파동전파), Docker 인프라 구축·배포

### [에코피스 / 2023.08 ~ 2023.10]
- 수질로봇에 AI 머신러닝 기반 수질예측 모델 탑재, 백엔드·프론트엔드 풀스택 개발
