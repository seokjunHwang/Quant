# 다올투자증권 — 국내 투자정보 개발 및 운영 경력사원 채용

## 1. 채용부문

| 항목 | 내용 |
|---|---|
| 구분 | **경력** |
| 모집분야 | **국내 투자정보 개발 / 운영** |

### 직무 내용
- 국내 시세 **FEP(Front-End Processor)**, 투자정보 개발 및 운영
- 외부기관 데이터 송수신 및 처리
- 뉴스, 차트 서비스 개발 및 운영
- **한국거래소, 넥스트레이드** 제도개편 대응
- **리눅스 기반 서버 플랫폼** 운영
- 서버 공통 개발 및 운영, 모니터링

### 자격요건
- 학사 이상의 학력 보유자
- **관련 업무 1년 이상 경력 보유자**

### 우대사항
- IT 및 금융관련 자격증 보유자

## 4. 본인 매칭 점검

| 항목 | 본인 매칭 |
|---|---|
| 학사 이상 | ⭕ 조선대 학사 + 서강대 석사 재학 |
| **관련 업무 1년 이상 경력** | 🟡 정확히 '투자정보 개발/운영'은 아니지만, AI 개발·트레이딩 알고리즘·차트지표·실서버 배포 경력 2년+ 보유 |
| 리눅스 서버 플랫폼 | ⭕ Docker·AWS·On-premises GPU 환경 구축 경험 (서울아산병원, 오퍼레잇) |
| 외부기관 데이터 송수신·처리 | 🟡 업비트 API 연동, 검색 API·DB 조회 모듈 구축 경험 |
| 차트 서비스 개발·운영 | ⭕ 오퍼레잇 — Python·PineScript 차트지표 개발, AI 차트예측 모델 실서버 배포 |
| 한국거래소·넥스트레이드 제도 | ❌ 직접 경험 없음 (학습 가능) |
| IT/금융 자격증 | ❌ 보유 자격증은 ITQ, 한국사 1급, 교원자격증 등 (금융권 자격증 없음) |

### ⚠️ 검토 필요 포인트

1. **이 공고는 '운용/리서치' 트랙이 아니라 '투자정보 인프라/IT 운영' 트랙**입니다. 본인이 그동안 정렬해 온 AI 퀀트·리서치 방향과는 약간 결이 다릅니다.
   - **장점**: 본인의 풀스택·서버·인프라 역량(Docker, AWS, GPU 환경, 실서비스 배포)이 잘 맞물림
   - **단점**: 정통 IT 운영 경력자(FEP, 거래소 시세 데이터 다뤄본 경력자)와 직접 경쟁 시 도메인 갭이 있음

2. **이미 [다올투자증권] 입사지원서 경력.docx 파일**이 폴더에 들어 있음 — 이미 지원 준비 중인 트랙으로 보임. 자소서나 입사지원서 작업 필요하시면 .docx 파일 변환·정리부터 도와드릴 수 있음.
