### 7-1. TCT-1176 / JACC 학회 초록 1저자 등재 (2025.10.22)

| 항목 | 내용 |
|------|------|
| 수상명 | 글로벌 임상학회 초록 1저자 등재 |

| 게재지 | **JACC**, Volume 86, Number 17_Supplement |
| Abstract ID | **TCT-1176** |
| 발표제목 | Fully Automated Deep Learning Model for Aortic Segmentation and Annulus Quantification in Pre-TAVR CT |
| 등급 | **1저자 (제1저자)** |
| 저자 (총 6명) | **Seokjun Hwang**, Jihoon Kweon, Do-Yoon Kang, Duk-Woo Park, Seung-Jung Park, Jung-Min Ahn |
| 수여기관 | TCT학회 / JACC저널 |
| 수상일 | 2025.10.22 |

#### 주요내용
본 연구는 심혈관 시술 시 필수적인 **판막륜 크기 측정**의 효율성과 정확도를 높이기 위해 완전 자동화된 딥러닝 모델을 개발한 프로젝트입니다.
- **데이터**: 아산병원 환자 1,002명의 CT 영상
- **아키텍처**: EfficientNet-b4 백본의 U-Net++
- **성과**: 인간 전문가들 사이의 수동 측정 일치도(R² = 0.76)보다 더 뛰어난 **재현성(R² = 0.92)** 달성
- **임상 기여**: 딥러닝 기반 자동화 분석으로 임상현장 작업 시간 단축 및 최적 시술 계획 수립에 기여

### 14-2. 키 스토리: "도전" - 호주 워킹홀리데이

- 20세에 별 준비 없이 호주 워킹홀리데이
- 1년간 농장, 공장, 레스토랑 등 다양한 일경험
- "정말 배운다는 마인드 하나로 말도 잘 안 통하는 곳에서 맨땅에 헤딩"
- 인내심·시야 확장의 첫 큰 경험

### 14-3. 키 스토리: "실패같은 성공" - 차트 3D 원통화 실험

- 아산병원에서 대동맥 중앙선 추출하며 3D 데이터 다루던 중
- 퇴근 후 트레이딩하다 떠오른 호기심: **"주식 차트와 인버스 차트를 이어붙여 대동맥처럼 3D 원통형으로 만들어보면? array로 변환하면 평면에선 안 보이던 특이점이 잡힐까?"**
- 비트코인 시계열 데이터를 원통형으로 구현 → 다차원 array 변환
- AI agent 활용, 실무에서 쓴 **파동전파 알고리즘** 적용
- **결국 특이점은 못 찾음** → 그러나 다차원으로 비틀어본 시도 자체로 의미 있는 '삽질'
- "실패 속에서 파편이 튀어나와 성공에 영감을 준다"는 가치관

### 14-4. 키 스토리: "도메인 지식 0에서 JACC 1저자까지" - 아산병원 적응기

- 임상 교수님 미팅 용어 절반 모르는 상태로 시작
- AI 모델링은커녕 미팅 요약조차 못하는 상황 반복
- **미팅을 직접 녹음 → 끝나자마자 용어 검색 → 용어집 작성**
- 관련 논문 모두 찾아 읽으며 맥락 이해
- 직접 땅 파서 얻은 도메인 지식으로 알고리즘 창안 → 모델 적용
- → **JACC 1저자 등재**
- 교훈: "몰입과 성실한 노력은 절대 배신하지 않는다"
- 이 학습 방식이 새로운 도메인 빠른 적응의 기본기로 자리잡음

### 14-5. 키 스토리: "현직에서의 AI 실무 - 멀티 에이전트 파이프라인"

- 단순 AI에 코드 받아 쓰기가 아닌 **하네스 엔지니어링**
- 각 AI에게 **기획·생성·검수 역할 분배**
- 자동화 시스템 구축까지가 작업 범위
- 과거 며칠 밤새 만들던 자동매매 봇을 **수 시간 내 더 높은 퀄리티로 완성** + 서버·프론트 빌딩까지 제공
- 트레이딩 로직 설계 + 콘텐츠 전략 기획에 AI 역할 분배 접목 → 창의성·생산성 향상

### 14-6. 키 스토리: "최신 AI 기술 즉시 흡수 루틴"

- **Anthropic, Gemini의 Agent SDK·CLI가 업데이트될 때마다 즉시 기존 파이프라인에 테스트**
- 새 기능이 워크플로우 어느 구간에 얼마나 영향 주는지, 기존 프롬프트 구조를 어떻게 바꿔야 하는지 돌려봄
- ECCV (밀라노), CVPR (내슈빌) 직접 참석으로도 동일한 패턴
- "빠르게 바뀌는 AI 시장에서 새로운 도구를 두려워하지 않고 바로 실무에 접목" = 격차 만드는 무기
