# v07 서비스 — 시황 정보 제공

v05 파이프라인이 매일 만들어내는 데이터(step0~step2)를 일반 사용자용 웹 페이지로 노출하는 정보 제공 서비스.

## 포지션
- **추천 서비스 아님 / 정보 제공 서비스.** 점수·등급·매수·목표가 표현 사용 안 함.
- 모든 페이지 푸터에 면책 고정.

## 페이지 구조
- `/` — 오늘의 시황 (어젯밤 미장 + 오늘 국장 + 매크로 + 글로벌 이벤트)
- `/macro` — 매크로 대시보드 (단일 페이지)
- `/themes` — 테마 인덱스
- `/themes/{slug}` — 테마별 편입 종목 리스트
- `/archive` — 지난 시황 모아보기
- `/archive/{date}` — 특정 날짜 시황 스냅샷

## 데이터 소스
- v05 (`/workspace/Quant/v05_종목추천/data/{YYYYMMDD}/all/`)의 `step0/step1/step2` JSON을 직접 읽음.
- v07은 데이터 생성을 하지 않음. v05가 만든 데이터를 **읽기 전용**으로 활용.

## 실행
```bash
python3.12 -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8007
```
