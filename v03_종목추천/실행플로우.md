
## 핵심 로직: RSI 다이버전스 감지

### 원본

`/workspace/Quant/indicators/pine/rsi_divergence.pine` (TradingView Pine Script v6)

### Python 포팅

`backend/app/core/rsi_divergence.py` — Pine Script 함수를 1:1 대응 구현:

| Pine Script | Python | 역할 |
|-------------|--------|------|
| `ta.rsi(src, len)` | `calc_rsi(close, period)` | Wilder's smoothing RSI |
| `ta.pivotlow(osc, lbL, lbR)` | `find_pivot_lows(series, lb_left, lb_right)` | RSI 로컬 최저점 |
| `ta.pivothigh(osc, lbL, lbR)` | `find_pivot_highs(series, lb_left, lb_right)` | RSI 로컬 최고점 |
| `ta.valuewhen(cond, src, occ)` | `valuewhen(condition, source, occurrence)` | N번째 True 시점 값 |
| `ta.barssince(cond)` | `barssince(condition)` | True 이후 경과 바 수 |
| `_inRange(cond)` | `in_range` 조건문 | 피봇 간 5~60바 거리 체크 |

### 파라미터 (config.py에서 관리)

| 항목 | 기본값 |
|------|--------|
| RSI_PERIOD | 14 |
| PIVOT_LOOKBACK_LEFT | 5 |
| PIVOT_LOOKBACK_RIGHT | 5 |
| RANGE_LOWER | 5 |
| RANGE_UPPER | 60 |

### 감지되는 4종 시그널

| 타입 | 라벨 | 조건 |
|------|------|------|
| `regular_bullish` | Bull | 가격 Lower Low + RSI Higher Low |
| `hidden_bullish` | H Bull | 가격 Higher Low + RSI Lower Low |
| `regular_bearish` | Bear | 가격 Higher High + RSI Lower High |
| `hidden_bearish` | H Bear | 가격 Lower High + RSI Higher High |

## 데이터 수집

- **소스**: yfinance (미장 + 국장 모두)
- **방식**: 1시간봉 20일치 수집 → 4시간봉으로 리샘플링 (open=first, high=max, low=min, close=last, volume=sum)
- **병렬**: ThreadPoolExecutor (기본 10 workers)
- **KR 티커 형식**: `005930.KS` (코스피), `086520.KQ` (코스닥)

## 종목 풀 구성

- **JSON 기반**: `app/data/us_stocks.json`, `app/data/kr_stocks.json`
- **Core Pool (70%)**: 분기 리밸런싱, 필터 기준 통과 확정 종목
- **Trending Pool (30%)**: 2주 갱신, 테마/이슈 기반 교체
- **필터 기준**: 시총 (US $2B~$50B / KR 5천억~10조), 유동성, 변동성(Beta 0.8~1.8), 리스크(D/E<200%), 트렌드(20SMA>60SMA)
- **카테고리**: US 6개 (AI/반도체, 클라우드/SaaS, 바이오, 소비재, 에너지, 산업재/방산), KR 6개 (반도체, 2차전지, 바이오, 방산/조선, 엔터/플랫폼, 로봇/AI)

## 스케줄링

- APScheduler가 **4시간마다** 자동 스캔 (`main.py` lifespan에서 시작)
- 수동 트리거: `POST /api/v1/scan/trigger`
- 결과는 메모리 캐시 (`scanner.py`의 `_last_scan`)
