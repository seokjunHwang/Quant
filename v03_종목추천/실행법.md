# 2. 주요 페이지

| URL | 설명 |
|-----|------|
| `/` | RSI Divergence Screener (종목 스캔 결과) |

## 3. 차트 지표 구조

### 현재 지원 지표

| 지표 | 타입 | 설명 |
|------|------|------|
| RSI Divergence | separate pane | RSI 기반 정규/히든 다이버전스 탐지 |
| TSR | overlay | 피봇 기반 트렌드 라인 + 지지/저항 존 |

차트 좌측 **Indicators** 패널에서 각 지표를 눈 아이콘으로 on/off, 톱니바퀴로 설정 변경 가능.

### 데이터 흐름

```
yfinance → data_fetcher.py → 지표별 core 로직 → chart.py API → TvChart.tsx
            OHLCV 수집         RSI Div / TSR        JSON 반환     차트 렌더링
```

| 파일 | 역할 |
|------|------|
| `backend/app/core/data_fetcher.py` | yfinance에서 1h 캔들 수집 → 4h 리샘플링 (선물 ETH 자동감지) |
| `backend/app/core/rsi_divergence.py` | RSI Divergence 전략 래퍼 |
| `backend/app/core/tsr.py` | TSR (트렌드 라인, 지지/저항) 래퍼 |
| `indicators/converted/rsi_divergence.py` | RSI Divergence 핵심 로직 (Pine Script 변환) |
| `indicators/converted/tsr.py` | TSR 핵심 로직 (Pine Script 변환) |
| `backend/app/api/chart.py` | API 엔드포인트 (`/{ticker}` RSI, `/{ticker}/tsr` TSR) |
| `backend/app/models/schemas.py` | 응답 데이터 모델 |
| `frontend/src/lib/indicator-types.ts` | 인디케이터 레지스트리 (지표 메타데이터, 파라미터 정의) |
| `frontend/src/components/chart/TvChart.tsx` | Lightweight Charts 렌더링 (멀티 인디케이터) |
| `frontend/src/components/chart/IndicatorPanel.tsx` | 좌측 인디케이터 패널 UI |
| `frontend/src/components/chart/plugins/trend-line.ts` | 트렌드 라인 플러그인 |
| `frontend/src/components/chart/plugins/box-primitive.ts` | S/R 존 박스 플러그인 |

### Step 2: 백엔드 래퍼 + 스키마 + API

```
backend/app/core/macd.py          → thin wrapper (import from indicators/converted/)
backend/app/models/schemas.py     → 응답 모델 추가
backend/app/api/chart.py          → GET /{ticker}/macd 엔드포인트 추가
```

### Step 3: 프론트엔드 — 데이터 레이어

```
frontend/src/lib/chart-types.ts      → 타입 추가
frontend/src/lib/api.ts              → getMacdData() 함수 추가
frontend/src/hooks/useMacdData.ts    → SWR 훅 추가
frontend/src/lib/indicator-types.ts  → INDICATOR_REGISTRY에 등록
```

### Step 4: 프론트엔드 — 렌더링

`TvChart.tsx`에서 새 데이터를 받아서 렌더링:
- 마커 (화살표 등): `createSeriesMarkers()`
- 라인: `TrendLinePrimitive` 사용
- 박스: `BoxPrimitive` 사용
- 새 패널 (MACD 등): `chart.addSeries(LineSeries, {...}, paneIndex)` 추가
