# 실행법

## 1. 실행 순서

### 백엔드 (FastAPI, port 8000)

```bash
cd v03_종목추천/backend
pip install -r requirements.txt   # 최초 1회
uvicorn app.main:app --reload --port 8000
```

### 프론트엔드 (Next.js, port 3000)

```bash
cd v03_종목추천/frontend
npm install                        # 최초 1회
npm run dev
```

브라우저에서 `http://localhost:3000` 접속.

---

## 2. 주요 페이지

| URL | 설명 |
|-----|------|
| `/` | RSI Divergence Screener (종목 스캔 결과) |
| `/chart` | 티커 입력 페이지 |
| `/chart/AAPL` | 해당 티커의 4H RSI 다이버전스 차트 |

티커 입력: `AAPL`, `NQ1!`, `NASDAQ`, `BTC` 등 (TradingView 티커, 별칭 모두 지원)

---

## 3. 차트 지표가 나오는 파일 (데이터 흐름)

```
yfinance → data_fetcher.py → rsi_divergence.py → chart.py → TvChart.tsx
            1h→4h 리샘플링      RSI+다이버전스탐지     JSON API     차트 렌더링
```

| 파일 | 역할 |
|------|------|
| `backend/app/core/data_fetcher.py` | yfinance에서 1h 캔들 수집 → 4h 리샘플링 (선물 ETH 자동감지) |
| `backend/app/core/rsi_divergence.py` | **전략 로직 핵심.** RSI 계산 → 피봇 탐지 → 다이버전스 시그널 생성 |
| `backend/app/api/chart.py` | API 엔드포인트. 위 2개 호출 → 캔들+RSI+시그널+라인 JSON 반환 |
| `backend/app/models/schemas.py` | 응답 데이터 모델 (CandleData, DivergenceLine 등) |
| `frontend/src/components/chart/TvChart.tsx` | Lightweight Charts로 캔들+RSI+다이버전스라인 렌더링 |
| `frontend/src/components/chart/plugins/trend-line.ts` | 다이버전스 라인 그리기 플러그인 |

---

```python
    # Signal 객체 리스트 반환 (시간, 가격, 타입 등)
    ...
```

### Step 2: 백엔드 — schemas.py에 응답 모델 추가 (필요시)

기존 `DivergenceLine`, `SignalMarker` 등을 재활용하거나, 새 모델 추가.

### Step 3: 백엔드 — chart.py에서 호출

```python

```

### Step 4: 프론트 — TvChart.tsx에서 렌더링

`TvChart.tsx`에서 새 데이터를 받아서 마커/라인 추가:
- 마커 (화살표 등): `candleSeries.setMarkers([...])`
- 라인 (다이버전스 등): `TrendLinePrimitive` 사용
- 새 패널 (MACD 등): `chart.addPane()` → `LineSeries` 추가
