# RSI 다이버전스 스크리너 — 종목 선별 기준 & 카테고리 설계

## 프로젝트 개요

4시간봉 기준 최근 15일치 데이터에서 RSI 다이버전스가 발생한 종목을 탐지하고, 최근 시그널 발생순으로 추천하는 스크리너 프로젝트.  
미장(US)·국장(KR) 각 약 50종목, 총 100종목 내외의 풀을 운영한다.

---

## 1. 시가총액 기준 (Mid-Cap 존)

| 시장 | 범위 | 이유 |
|------|------|------|
| **미장 (US)** | $2B ~ $50B | 대형주 대비 변동성 확보, 소형주 대비 유동성·안정성 |
| **국장 (KR)** | 5,000억 ~ 10조 원 | 코스피 중형주 + 코스닥 대형주 영역 |

> 너무 작으면 유동성 리스크, 너무 크면 변동성이 죽어서 RSI 다이버전스 시그널의 실효성이 떨어진다.

---

## 2. 핵심 필터링 조건

### 2-1. 유동성 & 거래량

- 일평균 거래대금 (최근 20일 기준)
  - 미장: **$10M 이상**
  - 국장: **50억 원 이상**
- 4시간봉 캔들이 정상적으로 형성될 수 있는 충분한 거래량 필수

### 2-2. 변동성 (적당한 수준)

- **ATR(14)** 기준 일일 변동률: **1.5% ~ 5%**
- 또는 **베타(β)**: **0.8 ~ 1.8**
- 너무 낮으면 시그널이 나와도 수익폭이 없고, 너무 높으면 리스크 과다

### 2-3. 리스크 관리 필터

| 항목 | 기준 |
|------|------|
| 부채비율 (D/E Ratio) | 200% 이하 |
| 최근 실적 | 직전 2분기 연속 적자 아닌 종목 |
| 상장 기간 | IPO 후 최소 1년 이상 (데이터 안정성) |
| 공매도 비율 (미장) | 15% 이하 |

### 2-4. 트렌드 필터

- 최근 3개월 섹터/테마 관심도 상승 (뉴스 빈도, 검색량 등)
- **20일 이평선 > 60일 이평선** → 중기 상승 추세에서의 다이버전스가 더 유의미
- 하락 추세에서 **상승 다이버전스**를 잡고 싶다면 이 조건을 역전 적용

## 4. 종목 리스트 갱신 전략

고정 리스트와 동적 리스트를 병행 운영한다.

### Core Pool (70%)

- **리밸런싱 주기**: 분기 1회
- 위 필터링 기준(시총, 유동성, 변동성, 리스크)을 통과한 확정 종목

### Trending Pool (30%)

- **갱신 주기**: 2주마다
- 최근 테마·이슈 기반으로 교체
- 소스: 섹터 ETF 자금유입, 뉴스 키워드 빈도, 거래량 급등 종목

## 5. RSI 다이버전스 감지 로직

### 기본 원리

- **상승(Bullish) 다이버전스**: 가격 저점은 낮아지는데, RSI 저점은 높아짐 → 매수 시그널
- **하락(Bearish) 다이버전스**: 가격 고점은 높아지는데, RSI 고점은 낮아짐 → 매도 시그널

### 탐지 파라미터

| 항목 | 설정 |
|------|------|
| 타임프레임 | 4시간봉 |
| 탐색 기간 | 최근 15일 (약 60~90개 캔들) |
| RSI 기간 | 14 |
| 피크/밸리 비교 | 최소 2개 이상의 저점 또는 고점 비교 |

### 출력 정렬

- 다이버전스 발생 시점이 **가장 최근인 순서**로 정렬
- 카테고리별 필터링 지원

## 6. 프로젝트 아키텍처

```
[종목 풀 관리]  →  [데이터 수집 (4h 캔들)]  →  [RSI 다이버전스 감지]  →  [결과 정렬·출력]
      │                     │                          │                        │
 JSON/DB로            yfinance (미장)            피크/밸리 비교           최근 시그널
 카테고리 태깅        pykrx/한투API (국장)       + RSI 비교 로직          발생순 정렬
```

### 기술 스택 (권장)

| 구성 요소 | 도구 |
|-----------|------|
| 데이터 수집 (미장) | `yfinance` |
| 데이터 수집 (국장) | `pykrx` 또는 한국투자증권 Open API |
| RSI 계산 | `ta` 라이브러리 또는 직접 구현 |
| 피크/밸리 탐지 | `scipy.signal.argrelextrema` |
| 종목 풀 관리 | JSON 파일 또는 SQLite |
| 시각화 (선택) | React 대시보드 또는 Streamlit |
