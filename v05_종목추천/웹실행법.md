# v05 웹 대시보드 실행법

## 최초 1회 설치

```bash
# cloudflared 설치 (외부 접속용 터널)
curl -Lo /usr/local/bin/cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 && chmod +x /usr/local/bin/cloudflared
```

## 파이프라인 실행 → 웹 자동 반영

```bash
cd /workspace/Quant/v05_종목추천
python main.py
```
> main.py 완료 시 `web/data/` 자동 빌드. 별도로 `build_web.py` 안 돌려도 됨.

과거 데이터 일괄 빌드가 필요하면:
```bash
python build_web.py --all
```

## 웹 서버 띄우기

### 로컬만 (이 PC에서만)
```bash
npx serve web -l 3000
```
→ `http://localhost:3000`

### 로컬 + 외부 접속 (다른 PC/폰)
```bash
npx serve web -l 3000 &
cloudflared tunnel --url http://localhost:3000
```
→ 터미널에 `https://xxxxx.trycloudflare.com` 링크 출력
→ 다른 PC/폰에서 해당 링크로 접속 가능

## VSCode 껐다 켰을 때

```bash
cd /workspace/Quant/v05_종목추천
npx serve web -l 3000 &
cloudflared tunnel --url http://localhost:3000
```
> `web/data/`에 데이터가 남아있으면 빌드 없이 바로 서버만 띄우면 됨.

## 종료

- `Ctrl+C` → cloudflared 종료 (외부 링크 비활성화)
- 백그라운드 서버 종료: `kill %1`

## 정리

| 상황 | 명령 |
|------|------|
| 파이프라인 실행 (웹 자동 반영) | `python main.py` |
| 서버 띄우기 (로컬) | `npx serve web -l 3000` |
| 서버 + 외부 터널 | 위 + `cloudflared tunnel --url http://localhost:3000` |
| 과거 데이터 일괄 빌드 | `python build_web.py --all` |
| 캐시 삭제 후 재실행 | `rm -rf data/YYYYMMDD && python main.py` |
