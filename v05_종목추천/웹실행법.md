# MarketPulse 웹 대시보드 실행법

> v05 종목추천 파이프라인 + 실시간 시장 분석 대시보드

## 최초 1회 설치

```bash
# 패키지 설치
cd /workspace/Quant/v05_종목추천
pip install -r requirements.txt
pip install fastapi "uvicorn[standard]" youtube-transcript-api "httpx>=0.27" googletrans==4.0.0-rc1

# cloudflared 설치 (외부 접속용 터널)
curl -Lo /usr/local/bin/cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 && chmod +x /usr/local/bin/cloudflared
```

> **주의**: `httpx`는 **0.27 이상**을 설치해야 `AsyncClient`가 정상 작동합니다. 옛 버전(0.13 등)이 먼저 설치돼 있으면 `pip install --upgrade httpx` 실행.

## 파이프라인 실행 → 웹 자동 반영

```bash
cd /workspace/Quant/v05_종목추천
python3.12 main.py
```
> main.py 완료 시 `web/data/` 자동 빌드. 별도로 `build_web.py` 안 돌려도 됨.

과거 데이터 일괄 빌드가 필요하면:
```bash
python3.12 build_web.py --all
```

## 웹 서버 띄우기 (FastAPI)

### 로컬만 (이 PC에서만)
```bash
cd /workspace/Quant/v05_종목추천
python3.12 -m uvicorn server:app --reload --host 0.0.0.0 --port 3001
```
→ `http://localhost:3001`
→ `--reload`로 띄우면 파일 수정 시 자동 재시작 (개발 편의)

### 로컬 + 외부 접속 (다른 PC/폰)
```bash
cd /workspace/Quant/v05_종목추천
python3.12 -m uvicorn server:app --reload --host 0.0.0.0 --port 3001 &
cloudflared tunnel --url http://localhost:3001
```
→ 터미널에 `https://xxxxx.trycloudflare.com` 링크 출력
→ 다른 PC/폰에서 해당 링크로 접속 가능

### 서버 프로세스 종료
```bash
# uvicorn 프로세스 종료
kill $(ps aux | grep uvicorn | grep -v grep | awk '{print $2}')
```

### UI 세부
- 상단 우측: **☀️ Light / 🌙 Dark** 토글 (localStorage 저장)
- 상단 중앙: **LIVE 뱃지** (매크로·속보 폴링 중 자동 표시, 초록 점멸)
- 속보 피드: 각 기사마다 UTC·KST 시간 + "N분 전" 상대 시각 자동 갱신
- AI 분석: 진입 시 블러 처리, 비번 입력 후 해제. 새로고침 시 다시 잠김.

## 알려진 이슈

- **YouTube RSS 404/500**: YouTube가 서버 IP를 일시 차단한 경우. 보통 몇 시간~24시간 후 자동 복구. 코드 문제 아님.
- **TradingView KOSPI/KOSDAQ**: 무료 플랜에서 `KRX:KOSPI`·`KRX:KOSDAQ` 지원 제한적. 심볼 못 찾으면 기본값으로 폴백.
- **Tailwind CDN 경고**: 개발 중에는 무시. 프로덕션 배포 시 빌드 툴 사용 권장.
- **AI 분석 탭 비밀번호**: `2759` (앱 내부 하드코딩, 개인용).
