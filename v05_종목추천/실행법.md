### 인증 풀

| 풀 | 한도 | 일일 사용량 | 사용률 |
|---|---|---|---|
| 🟦 Gemini CLI 구독 (Pro) | 1,500 호출/일 | ~11회 | 0.7% |
| 🟪 Claude CLI 구독 (Sonnet 4.6) | 구독 한도 | ~7회 | 충분 |
| 🟨 Gemini API key (Flash) | 검색 5,000회/월 | ~10~20 검색쿼리/일 | <10% |

> 세 풀이 **완전히 분리**되어 한쪽이 소진돼도 영향 없음.
> Step 3 안전망: CLI 구독 잔량 < 30이면 자동 API key Flash로 fallback.

## 1. 환경 설정 (최초 1회)

```bash
cd /workspace/Quant/v05_종목추천
pip install -r requirements.txt
pip install fastapi "uvicorn[standard]" youtube-transcript-api "httpx>=0.27" googletrans==4.0.0-rc1
```

> `httpx`는 **0.27 이상** 필요 (옛 버전은 `AsyncClient` 호환 안 됨). 이미 설치된 경우 `pip install --upgrade httpx`.

### CLI 도구 OAuth 로그인 (브라우저 한 번씩)

```bash
# Claude CLI — Sonnet 4.6
claude               # → /login → Google/Anthropic 계정 인증

# Gemini CLI — gemini-3.1-pro-preview
gemini               # → "Sign in with Google" → Google AI Pro 구독 계정 인증
```

> 두 CLI 모두 OAuth 토큰이 로컬 캐시되므로 이후 자동 인증.

## 2. API 키 확인

`config/api_keys.env` 파일:
```
GEMINI_API_KEY=...   # Step 1 뉴스 검색 (Flash) 용
DART_API_KEY=...     # 한국 공시
```

- **Gemini API key**: Google AI Studio에서 발급 (무료 월 5,000 검색쿼리)
- **DART**: DART OpenAPI에서 발급 (무료, 일 10,000건)
- **Claude / Gemini CLI 구독**: 위 OAuth로 자동 인증, 추가 키 불필요

## 3. 실행

### 즉시 실행
```bash
python3.12 main.py              # 전체 시장 (국장+미장)
python3.12 main.py --market kr  # 국장만
python3.12 main.py --market us  # 미장만
```
> 실행 완료 시 웹 대시보드 데이터(`web/data/`)도 자동 빌드됩니다.

### 자동 실행 (매일 06:30 KST 평일)
```bash
python3.12 main_schedule.py                  # 전체 시장
python3.12 main_schedule.py --market kr      # 국장만
```
> 종료: `Ctrl+C`

### 특정 단계부터 재실행 (캐시 활용)
```bash
python3.12 main.py --from step0    # 글로벌 이벤트부터
python3.12 main.py --from step1    # 뉴스 수집부터
python3.12 main.py --from step2    # 테마 분석부터
python3.12 main.py --from step3    # 종목 리서치부터
python3.12 main.py --from step5    # 리포트만 재생성
```

### 캐시 삭제 후 재실행
```bash
rm -rf data/YYYYMMDD              # step별 캐시 삭제
rm -rf data/cache/step3/YYYYMMDD  # step3 종목 리서치 캐시 삭제
python3.12 main.py
```
> step3 캐시는 별도 위치(`data/cache/step3/{date}/`). 같은 날 안에서는 종목별로 재호출 안 함.

### 드라이런 (AI 호출 없이 매크로+DART만)
```bash
python3.12 main.py --dry-run
```
> 주의: dry-run 캐시가 남으면 다음 실행에서 빈 데이터로 스킵됨. 캐시 삭제 후 정상 실행할 것.

## 4. 파이프라인 구조

```
Step 0: 글로벌 이벤트 수집
  ├─ 🟦 Gemini CLI Pro × 3회 → 지정학/전쟁, 정책/무역, 에너지/기술/재해
  ├─ 🟦 Gemini CLI Pro × 2회 → 경제 캘린더 (미국/유럽 + 아시아)
  ├─ 🟪 Claude CLI Sonnet × 1회 → 이벤트 영향 분석 + 좌표 + 종목 연결
  └─ → web/data/events_YYYYMMDD.json (글로벌맵용)

Step 1: 데이터 수집
  ├─ 🟨 Gemini API key (Flash) → 국장/미장 뉴스 (실시간 속보)
  ├─ yfinance → 매크로 지표 (VIX, S&P500, 환율 등)
  └─ DART API → 오늘 공시 (참고용)

Step 2: 테마 분석
  └─ 🟪 Claude CLI Sonnet × 1회 → 유효 테마 5~7개 + 종목 힌트
      테마당: 국장 3개(대1+중2) + 미장 7개(대2+중5)

Step 3: 종목 리서치 + 필터링
  ├─ 테마별 후보 풀 (~35개) → DART 리스크 필터
  ├─ 🟦 Gemini CLI Pro × ~6회 → 5종목씩 배치 리서치 (KR 8 + US 18)
  │      └ 캐시 적중시 호출 0 / quota 부족시 🟨 Flash fallback
  ├─ DART 재무 데이터 (국장만)
  └─ yfinance/pykrx → 시총 수집

Step 4: 차트 분석 (코드 룰 기반, AI 호출 없음)
  ├─ yfinance/pykrx → OHLCV 60일 수집
  └─ Python 룰 → RSI, 볼린저밴드, MACD, 거래량비율 → chart_score

Step 5: 최종 점수 + 리포트
  ├─ 종합 점수: 테마(30%) + 차트(30%) + 수급(20%) + 재무(20%)
  ├─ 🟪 Claude CLI + WebSearch → 향후 일정 검색 (5종목 배치 × ~3회)
  └─ 🟪 Claude CLI × 1회 → 최종 투자 리포트 생성

→ 웹 대시보드 데이터 자동 빌드 (web/data/)
→ 글로벌 이벤트맵 데이터 자동 빌드 (web/data/events_*)
```
