# v05 종목 추천 파이프라인 — 실행법

## 1. 환경 설정 (최초 1회)

```bash
cd /workspace/Quant/v05_종목추천
pip install -r requirements.txt
```

## 2. API 키 확인

`config/api_keys.env` 파일:
```
GEMINI_API_KEY=...
DART_API_KEY=...
```

- **Gemini**: Google AI Studio에서 발급 (무료 월 5,000 검색쿼리)
- **DART**: DART OpenAPI에서 발급 (무료, 일 10,000건)
- **Claude CLI**: Max 구독 OAuth 자동 인증 (추가 과금 없음)

## 3. 실행

### 즉시 실행
```bash
python main.py              # 전체 시장 (국장+미장)
python main.py --market kr  # 국장만
python main.py --market us  # 미장만
```
> 실행 완료 시 웹 대시보드 데이터(`web/data/`)도 자동 빌드됩니다.

### 자동 실행 (매일 06:30 KST 평일)
```bash
python main_schedule.py                  # 전체 시장
python main_schedule.py --market kr      # 국장만
```
> 종료: `Ctrl+C`

### 특정 단계부터 재실행 (캐시 활용)
```bash
python main.py --from step2    # step2부터
python main.py --from step3    # step3부터
python main.py --from step5    # 리포트만 재생성
```

### 캐시 삭제 후 재실행
```bash
rm -rf data/YYYYMMDD    # 예: rm -rf data/20260328
python main.py
```
> 캐시가 있으면 해당 step을 건너뛰므로, 완전 재실행 시 반드시 캐시 삭제 필요.

### 드라이런 (AI 호출 없이 매크로+DART만)
```bash
python main.py --dry-run
```
> 주의: dry-run 캐시가 남으면 다음 실행에서 빈 데이터로 스킵됨. 캐시 삭제 후 정상 실행할 것.

## 4. 파이프라인 구조

```
Step 1: 데이터 수집
  ├─ Gemini Google Search → 국장/미장 뉴스 (3회)
  ├─ yfinance → 매크로 지표 (VIX, S&P500, 환율 등)
  └─ DART API → 오늘 공시 (참고용)

Step 2: 테마 분석 (Claude CLI 1회)
  └─ 뉴스 + 매크로 → 유효 테마 6~10개 도출
      테마별 국장 2~3개 + 미장 5~8개 종목 힌트

Step 3: 종목 리서치 + 필터링
  ├─ 테마별 후보 종목 풀 생성 (~90개)
  ├─ DART 리스크 필터 (후보 국장만 유상증자/보호예수 체크)
  ├─ Gemini Search → 종목별 리서치 (KR 12 + US 25)
  └─ DART 재무 데이터 (국장만)

Step 4: 차트 분석 (Claude CLI × 최대 40회)
  ├─ yfinance/pykrx → OHLCV 60일 수집
  ├─ Python → RSI, 볼린저밴드, MACD, 거래량비율
  └─ Claude → 지표 해석 → 매매 타이밍 + chart_score

Step 5: 최종 점수 + 리포트
  ├─ 종합 점수: 테마(30%) + 차트(30%) + 수급(20%) + 재무(20%)
  ├─ Gemini Search → 향후 일정 검색 (5종목 배치 × ~6회)
  └─ Claude CLI → 최종 투자 리포트 생성

→ 웹 대시보드 데이터 자동 빌드 (web/data/)
```

## 5. 결과물 위치

```
data/
  YYYYMMDD/
    all/
      step1_데이터수집/     매크로 + 뉴스 + 공시
      step2_테마분석/       유효 테마 6~10개
      step3_종목필터링/     후보 종목 리서치 + DART 필터
      step4_차트분석/       기술적 지표 + 매매 타이밍
      step5_리포트/         최종 리포트 (JSON + MD)
  logs/
    search_usage.jsonl     Gemini 쿼리 누적
    claude_usage.jsonl     Claude 호출 기록

web/data/
  dates.json               날짜 인덱스
  YYYYMMDD.json            웹 대시보드용 데이터 (자동 생성)
```

## 6. AI 호출 횟수 (1회 실행 기준)

| 단계 | AI | 횟수 |
|------|----|------|
| Step 1 뉴스 | Gemini Search | 3회 |
| Step 2 테마 | Claude CLI | 1회 |
| Step 3 리서치 | Gemini Search | KR 12 + US 25 = 37회 |
| Step 4 차트 | Claude CLI | 최대 40회 |
| Step 5 일정 | Gemini Search | ~6회 |
| Step 5 리포트 | Claude CLI | 1회 |

**Gemini 쿼리: ~155/회 (무료 5,000/월 → 매일 실행 OK)**
**Claude: ~42회/회 (Max 구독 → 과금 없음)**
**최종 리포트: 국장 7개 + 미장 20개 = 최대 27종목**
