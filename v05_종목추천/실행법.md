# v05 종목 추천 파이프라인 — 실행법

## 1. 환경 설정

```bash
cd /workspace/Quant/v05_종목추천
pip install -r requirements.txt
```

## 2. API 키 확인

`config/api_keys.env` 파일:
```
GEMINI_API_KEY=...
DART_API_KEY=...
```

Claude CLI 로그인 (최초 1회):
```bash
claude auth login
```

## 3. 실행

### 즉시 실행
```bash
python main.py              # 전체 시장
python main.py --market kr  # 국장만
python main.py --market us  # 미장만
```

### 자동 실행 (매일 06:30 KST 평일)
실행하면 다음 06:30 KST까지 대기했다가 자동으로 파이프라인을 실행합니다.
종료는 `Ctrl+C`.

```bash
python main_schedule.py                        # 전체 시장
python main_schedule.py --market kr            # 국장만
python main_schedule.py --market us            # 미장만
python main_schedule.py --from step3           # step3부터 재실행
python main_schedule.py --dry-run              # AI 없이 데이터만
```

### 특정 단계부터 재실행 (캐시 활용)
오늘 이미 step1~2를 돌렸다면 캐시를 그대로 쓰고 원하는 단계부터 재실행 가능.
```bash
python main.py --from step2    # step2부터
python main.py --from step3    # step3부터
python main.py --from step5    # 리포트만 재생성
```
`main_schedule.py`도 동일하게 `--from` 옵션 지원.

### 드라이런 (AI 호출 없이 데이터만 수집)
```bash
python main.py --dry-run
```

## 4. 파이프라인 구조

```
Step 1: 데이터 수집
  ├─ Gemini Google Search → 국장/미장 뉴스
  ├─ yfinance → 매크로 지표 (VIX, S&P500, 환율 등)
  └─ DART API → 유상증자/보호예수 공시

Step 2: 테마 분석 (Claude CLI)
  └─ 뉴스 + 매크로 → 오늘 유효 테마 3~5개 도출

Step 3: 종목 리서치 + 필터링
  ├─ 테마별 후보 종목 풀 생성
  ├─ DART 리스크 제외 (유상증자 -30점, 보호예수 -20점)
  ├─ Gemini Search → 개별 종목 호재/악재/뉴스
  └─ DART 재무 데이터 (국장만)

Step 4: 차트 분석 (Claude CLI)
  ├─ pykrx/yfinance → OHLCV 수집
  ├─ RSI, 볼린저밴드, MACD, 거래량 계산
  └─ Claude → 매매 타이밍 판단

Step 5: 최종 점수 + 리포트 (Claude CLI)
  ├─ 종합 점수: 테마(30) + 차트(30) + 수급(20) + 재무(20)
  └─ Claude → 투자 리포트 생성
```

## 5. 결과물 위치

```

```

## 6. AI 호출 횟수 (1회 실행 기준)

| 단계 | AI | 횟수 |
|------|----|------|
| Step 1 뉴스 | Gemini Search | 3회 (국장1 + 미장1 + 프리마켓1) |
| Step 2 테마 | Claude CLI | 1회 |
| Step 3 리서치 | Gemini Search | 종목수 × 1 (최대 40회) |
| Step 4 차트 | Claude CLI | 종목수 × 1 (최대 30회) |
| Step 5 리포트 | Claude CLI | 1회 |

**총 Claude 호출: 최대 32회 / Gemini 검색: 최대 43회**
