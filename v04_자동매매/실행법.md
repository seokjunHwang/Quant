## 0. 사전 준비

### API 키 발급

| 서비스 | 필수? | 용도 | 발급처 |
|--------|-------|------|--------|
| **Gemini AI** | **필수** | AI 분석/판단 | https://aistudio.google.com/apikey |
| FRED | 선택 | 매크로 데이터 (yfinance로 대체 가능) | https://fred.stlouisfed.org/docs/api/api_key.html |
| Finnhub | 선택 | 뉴스, 내부자 거래 | https://finnhub.io/register |
| Alpaca | 선택 | 주가 데이터 (yfinance로 대체 가능) | https://app.alpaca.markets/signup |

> Gemini 키만 있으면 Phase 0 ~ Step 5 전부 돌릴 수 있음.

### 키 설정

```bash
cp config/api_keys.env.example config/api_keys.env
```

`config/api_keys.env` 열어서 발급받은 키 입력.

### 패키지 설치

```bash
pip install -r requirements.txt
```

## 1. 전체 플로우

```
[Phase 0] 로직체인 DB 구축 (최초 1회)
    │
    │  "금리인하 → 성장주 수혜" 같은 인과관계 500개를
    │   Gemini가 생성 → 벡터화 → ChromaDB에 저장
    │   (20개 카테고리 × 25개씩)
    │
    ▼
[Phase 1] 분석 파이프라인 (수동 실행 or 자동 반복)
    │
    ├─ Step 1. 매크로 데이터 수집
    │   금리, 달러, VIX, 유가 등 거시경제 지표 수집
    │   → 이상 신호 탐지
    │
    ├─ Step 2. AI 역추론 (Gemini 1회 호출)
    │   이상 신호 → "왜 이런 움직임?" 원인 추론
    │   → 로직체인 DB에서 유사 패턴 매칭
    │   → 수혜 섹터 도출
    │
    ├─ Step 3. 종목 필터링
    │   수혜 섹터에서 시총/거래량/공매도 기준으로 후보 추림
    │
    ├─ Step 4. 차트 스코어링
    │   기술적 지표(RSI, VWAP, 볼린저) + 세력 패턴 점수화
    │
    └─ Step 5. 통합 스코어링 (Gemini 1~5회 호출)
        전 단계 점수 합산 → 60점 이상만 AI 최종 판단
        → 추천 종목 + 근거 출력
        → 매매는 직접 수동으로 진행
```

## 2. 실행 명령어

### Phase 0: 로직체인 DB 구축 (최초 1회)

```bash
python main.py --phase0
```

- Gemini가 20개 카테고리 × 25개 = **500개** 로직체인 생성
- 벡터화 후 ChromaDB에 저장 (`data/chromadb/`)
- JSON 원본도 보관 (`data/logic_chains/`)
- Gemini **20회 호출**, 카테고리 간 3초 쿨다운
- 소요시간: 약 10~15분

### 분석 파이프라인 1회 실행

```bash
python main.py
```

- Step 1~5 순서대로 1회 실행
- Gemini **2~6회 호출**
- 결과: `data/collected/run_YYYYMMDD_HHMMSS.json`

### 자동 반복 모드

```bash
python main.py --loop
```

- 5분마다 자동 분석 반복
- 미장 시간(한국시간 23:30~06:00)에 맞춰 돌리면 됨
- `Ctrl+C`로 중단

## 4. 실행 순서 요약

```
1. config/api_keys.env 에 Gemini API 키 입력
2. pip install -r requirements.txt
3. python main.py --phase0       ← 로직체인 DB 구축 (최초 1회)
4. python main.py                ← 분석 실행 → 추천 종목 확인 → 수동 매매
```
