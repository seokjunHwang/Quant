# v08 하네스 엔지니어링 — 실행법

## 설치
```bash
pip install -r requirements.txt
```

## 실행
```bash
# CLI 백엔드 (구독 정액, 무료)
python main.py --task "binance 호가 수집기 만들기" --backend cli --rounds 5

# API 백엔드 (정밀 제어, 토큰 과금)
export ANTHROPIC_API_KEY=...
python main.py --task "..." --backend api --rounds 5
```

## 구조
- `core/` — 백엔드 추상화 (CLI/API 어댑터)
- `agents/` — 4스텝 페르소나 (Architect / Builder / Gatekeeper / Memory)
- `sandbox/` — Builder 산출물 격리 실행
- `knowledge/` — Rule.md (자가진화 룰), 실패 로그
- `tasks/{id}/round_NN/` — 라운드별 산출물 아카이브
- `config/settings.yaml` — 백엔드/모델/라운드 설정
